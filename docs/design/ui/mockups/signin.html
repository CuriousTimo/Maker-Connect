Same for both roles: who you are, and so what you see, is known only after you sign in.

POST /api/v1/session. Have an invite link? It opens a page to make your account (flows.md §7).

The error state
The name or the password is wrong. Try again. After several tries, wait a minute.

One message for both cases, so the page does not tell whether a name exists. The wait follows the hub's failure counter (flows.md §7); its numbers are not in the design yet.

First run

On a fresh hub: "Enter the setup code from the hub's log to make the first account." POST /setup makes the first account, its organisation and space.
