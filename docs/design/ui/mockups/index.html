Maker Connect v2: mockups

Static, clickable mockups of the v2 web UI. The target design is docs/design/ui.md; the study behind it is docs/plans/ui-ux-study.md. Use View as at the top right on any screen: Guest (Eli, looks only), Member (Sam), Admin (Noor) or Instance admin (Ada, also the space's owner). The theme button switches Auto, Light and Dark. All data is invented: the space Workshop North of the organisation Makers Guild, machines MINI-1, Laser-A and others. Blue dotted lines marked … are the spec behind a control (verb, action, call), for the builder: they are not the product's text.

Shared

  • Sign in, join by invite, first-run setup
  • Now: the space at a glance
  • Wall screen: Now on a TV, read only

Every role

Each shows what changes with the role.

  • Machines
  • MINI-1: now · queue · controls · files · cameras · machine · history · advanced
  • Print on MINI-1 (start a print)
  • Laser-A: place, frame with the laser off, PPE, Start burn by a person; states burning, lid open, alarm, ended, stopped, hub unreachable
  • Files, and replacing a laser's loaded job
  • Tape-1: tape printer (LabelManager PnP kind)
  • Labels-1: label printer (LabelWriter kind)
  • Materials and spool #12
  • Printer-3: ask for permission: pending, refused, granted, withdrawn
  • My permissions and your own requests (guest, member)
  • Queue and farm

Staff only

As a guest or member, each shows the refused page they would get.

  • Add machine: built-in Connect, USB through the agent, after Add
  • Space: members, roles, invites
  • Space: permissions (granting) and requests
  • Space: settings: API tokens, audit log, cameras, access

The agent

  • The agent's own page: its devices and their link to the hub, About (the computer, its load)

Instance admin

  • Instance: organisations and spaces, moving a machine, the hub's update

States

One screen each, on a real page.

  • Empty: Files, nothing uploaded yet
  • Loading: Jobs
  • Error: Cameras, the hub cannot be reached
  • Refused: Laser-A, Start burn not granted
  • Unknown: Printer-4 offline, values unknown, not zero
  • A command's answer (pending, done, refused, unknown): Laser-A, burning

The state list

One word and one colour per machine state, everywhere.

Free Printing Needs someone Attention Error Offline Unknown

Job and outcome tags are square, without the dot, and never a state's colour: Job loaded Done Stopped Low

with its reason under it

unknown is how a value without a basis is shown; a real zero is written 0.
