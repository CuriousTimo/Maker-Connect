Maker Connect v2: mockups

Static, clickable mockups of the v2 web UI. The target design is docs/design/ui.md; the study behind it is docs/plans/ui-ux-study.md. Use View as: User | Admin at the top right on any screen; the theme button switches Auto, Light and Dark. All data is invented: the space Workshop North, members Sam (member) and Noor (admin), machines MINI-1, Laser-A and others.

Shared

  • Sign in
  • Now: the space at a glance, and the wall screen

User and admin

Each shows what changes with the role.

  • Machines
  • MINI-1: overview · control · files · jobs · camera · settings
  • Print on MINI-1 (start a print)
  • Laser-A: load, frame at power 0, PPE, Start burn by a person
  • Tape-1: tape printer (LabelManager PnP kind)
  • Labels-1: label printer (LabelWriter kind)
  • Materials and spool #12
  • Printer-3: ask for permission, and its pending state
  • Queue and farm (members see their own queue items)

Admin only

As a member, each shows the refused page a member would get.

  • Add machine (pairing by code)
  • Space: members, roles, invites
  • Space: permissions (granting) and requests
  • Space: settings (general, API tokens, audit log, cameras, access)

Instance admin

  • Instance: organisations and spaces

States

One screen each, on a real page.

  • Empty: Files, nothing uploaded yet
  • Loading: Jobs
  • Error: Cameras, the hub cannot be reached
  • Refused: Laser-A, Start burn not granted
  • Unknown: Printer-4 offline, values unknown, not zero

The state list

One word and one colour per state, everywhere.

Free Printing Needs someone Attention Error Offline Unknown

unknown is how a value without a basis is shown; a real zero is written 0.

Not mocked

  • Prepare (the LaserFoundry web fork, the label editor: #6, #24)
  • Jobs, Files and Cameras as full pages: they appear here in a state
  • About and self-update (on the instance screen only)
