  1. What are you adding?

    A printer with built-in Connect: its own firmware connects to the hub, no agent.

  2. Point it here

    Put this file on the printer's USB stick as prusa_printer_settings.ini; then, on the printer, load the settings and add it to Connect.

    [service::connect]
hostname = 192.168.1.20
port = 8080
tls = false
    The address must fit in the printer's hostname field: 20 bytes for firmware 6.3.0. hub.workshop-north.example is 26 bytes, so the file uses this hub's IP address.
    today's INI lines (crates/hub/src/shell.js:89); the hub writes the lines for the printer's dialect

  3. Enter the code it shows

    POST /api/v1/devices/pair {code, name} · devices.manage

  4. Then: who may use it

    Set who may use it in Space → Permissions.

  1. What are you adding?

    A machine on USB: a 3D printer, a laser, a tape or label printer, a scale or a USB camera, through the agent on a computer beside it.

  2. Start the agent beside it

    On the computer the machine is plugged into, download the agent for that computer and start it against this hub. It then shows a code.

    Download the agent
    chmod +x maker-connect-agent-linux-aarch64
sudo usermod -aG dialout $USER   # once: serial ports, then log in again
./maker-connect-agent-linux-aarch64 run --hub http://192.168.1.20:8080 --name "My machine" --save
    today's downloads page and start command (crates/hub/src/downloads.rs:114); the v2 agent's own command follows its step

  3. Enter the code it shows

    POST /api/v1/devices/pair {code, name} · devices.manage (flows.md §1)

  4. Then: who may use it

    Set who may use it in Space → Permissions.

A network camera (RTSP) has no code: add it in Space → Cameras. A USB camera comes through the agent: pick A machine on USB.

Errors

That code is not waiting here. It may have expired: the printer or the agent shows a new one; enter that one.
The machine did not collect its token. It was added, but has not reported yet. Check that it is on and can reach this hub, then wait.
